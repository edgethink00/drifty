# Security policy

Please do not report security issues in public issues or pull requests.

Report a vulnerability privately through GitHub: open the **Security** tab of
this repository and choose **Report a vulnerability**. If that is not
possible, email support@drifty.so with "Security" in the subject.

Include the affected version, the steps to reproduce and the impact you
expect. We confirm receipt within three business days and keep you updated
until the issue is fixed. Please give us a reasonable time to release a fix
before disclosing it.

Only the latest release of the desktop app receives security fixes.
